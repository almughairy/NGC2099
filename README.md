# NGC 2099 (M37) Gaia Analysis

This repository contains an exploratory analysis of the open star cluster **NGC 2099 (M37)** using data from **Gaia DR2, Gaia EDR3, and Gaia DR3**.

The project retrieves astrometric and photometric data directly from the Gaia Archive using `astroquery` and performs an initial comparison of the three data releases. The long-term aim is to investigate cluster membership, stellar properties, and evolutionary characteristics using Gaia observations.

## Tools
- Python
- Astroquery
- Pandas
- NumPy
- Matplotlib
- Gaia Archive

**Status:** Ongoing research project.
